# Changelog

User-facing changes to bellhop. While it is on `0.x`, a minor release may break things.

## 0.1.1 - 2026-11-21

### Fixes

- Start the drainer on Pythons without spawn sessions

## 0.1.0 - 2026-11-21

### Features

- List live sessions from hooklinesinker
- Add the message store, the drainer and the messaging commands
- Reach pi sessions through the bellhop pi extension
- Reach codex sessions through their app server
- Reach claude sessions through the bellhop relay
- Launch and wake stopped agents in their own tmux sessions
- Add the bellhop skill, user guides, known limits and hand-off notes
- Add codex session servers and a trace log
- Add claude socket route

### Fixes

- Close the gaps the final reviews found in delivery, launch and doctor
